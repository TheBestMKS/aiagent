## Ограничение среды проверки

В текущей Linux-среде отсутствует исполняемый файл Dart/Flutter, а Windows-путь
`N:\\Codex\\Compilers\\flutter` недоступен. Поэтому здесь не запускались:

```text
flutter analyze
flutter test
flutter build windows
flutter build web
flutter build apk
```

На целевом компьютере полный цикл выполняется файлом `build_all.bat`. Он использует Flutter из `N:\\Codex\\Compilers\\flutter` и формирует артефакты версии из `pubspec.yaml`.
