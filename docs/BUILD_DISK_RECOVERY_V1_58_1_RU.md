# Восстановление сборки при нехватке места — v1.58.1

## Классификация

Сообщения `No space left on device`, `Недостаточно места на диске`, `disk full` и `errno = 112` относятся к окружению. Они не дают агенту права изменять Dart, C++, CMake или другие исходники.

## Предварительная проверка

`build.ps1` проверяет свободное место перед каждой платформой:

- Windows: рекомендуется не менее 2 ГБ;
- Web: не менее 1 ГБ;
- Android: по умолчанию не менее 3 ГБ.

Порог Android можно изменить через `-MinimumAndroidFreeSpaceGB`.

## Безопасная очистка

Автоматически разрешено удалять только генерируемые данные проекта:

- `build`;
- `.dart_tool/flutter_build`;
- `android/.gradle`;
- `android/.cxx`;
- `android/app/.cxx`.

Каталоги `lib`, `test`, `tools`, `Projects`, `config`, `plugins` и `dist` автоматической очисткой не затрагиваются. Старые версии в `dist` пользователь удаляет самостоятельно.

## Частично завершённый релиз

Если Windows и Web уже собраны, а Android завершился ошибкой, ZIP-файлы остаются в каталоге версии. Повторный `build_all.bat` пропустит существующие артефакты и продолжит отсутствующую платформу. Для принудительной пересборки всех платформ применяется `-ForceRebuild`.

## Повтор Android

Если Android-сборка завершилась ошибкой при остатке менее 1 ГБ, сборщик один раз очищает генерируемые данные, повторно проверяет место и повторяет ту же Android-команду. Бесконечных повторов нет.
