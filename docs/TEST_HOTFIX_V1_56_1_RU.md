# Исправление теста AIAgent 1.56.1

В версии 1.56.0 рабочая Windows-команда прямой C++-сборки формировалась правильно:

```text
(if not exist build mkdir build) & (if exist build\app.exe del /q build\app.exe) & g++.exe ...
```

Сбой происходил только в регрессионном тесте. Ожидаемый фрагмент был записан обычной Dart-строкой, поэтому обратные слэши Windows не сохранялись при сравнении.

Исправление:

- ожидаемые Windows-пути записаны как raw-строки `r'...'`;
- безопасная и небезопасная формы команды вынесены в отдельные константы;
- рабочий код `CppBuildCommandBuilder` не менялся.

На целевом компьютере необходимо повторно выполнить `build_all.bat`.
