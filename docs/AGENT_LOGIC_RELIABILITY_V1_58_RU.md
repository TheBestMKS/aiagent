# Надёжность логики агента в версии 1.58.0

## Причины изменений

По журналу выполнения агент выбрал OpenCV до проверки установки, использовал OpenCV DNN как предполагаемый движок обучения, угадывал путь `C:/msys64`, отправлял `replace_text` без `path`, повторял текст об успешной правке без инструмента и не восстанавливал отменённую задачу после команды «продолжай».

## Детерминированные ограничения

1. Preflight проверяет OpenCV, LibTorch и ONNX Runtime внутри `tools`.
2. План с неподтверждённой тяжёлой зависимостью должен сначала предусмотреть её локальную проверку/загрузку либо выбрать собираемый вариант без неё.
3. CMake-правка с несуществующим абсолютным путём блокируется до исполнения.
4. Tool-call проходит контракт обязательных аргументов. Для `replace_text` нужны `path`, `old_text`, `new_text`; `path=CMakeLists.txt` восстанавливается только однозначно.
5. JSON восстанавливается только от завершающей запятой перед закрывающей скобкой. Другие повреждения не угадываются.
6. Заявление об успехе без вызова инструмента не попадает в пользовательский ответ и не считается прогрессом.
7. Три некорректных действия или три одинаковых ответа без действий останавливают цикл.
8. `cmake --build .` с несуществующим `cwd=build` выполняется из корня с предварительной конфигурацией.
9. «Продолжай» загружает последний подходящий checkpoint из истории за 48 часов.
10. Непроверенная память помечается `TENTATIVE`; доверенная процедура требует фактической проверки и хотя бы одного исключённого подхода.
